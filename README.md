# Star

Tauri 2 + React + TypeScript foundation for the Star IDE.

The frontend initializes Monaco for the main editor, CodeMirror for lightweight
configuration editing, Ghostty Web for terminal rendering, Shiki for rendered
code, Tree-sitter for syntax context, Streamdown for streaming AI output, and
React Virtuoso for large activity timelines.

- `npm run dev` — browser development
- `npm run tauri dev` — desktop development
- `npm run build` — type-check and bundle
